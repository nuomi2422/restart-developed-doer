## 2. 设计要点

- **角色映射**（相位→角色）：`execution/execution_retry/goal_judging/compaction`→execution；`stage_a/stage_b/fallback`→planning；`review`→learning；其余→unknown（只计量不建策）。
- **配置**：`<configDir>/budget-policy.json`；不存在 = 默认（shadow、全部不限）。首次 install 另写 `budget-policy.example.json`（不覆盖）。
  - `mode`：**本版本只实现 shadow**；请求 `enforce` 会 warn 并按 shadow 执行（事件里如实标 `mode:"shadow"`）。
  - `windowMinutes`（默认 60，clamp 5–1440）、`adviceCooldownMinutes`（默认 5，clamp 1–60）。
  - `roles.<role>.{tokensPerWindow,callsPerWindow,minutesPerWindow}`，**0 = 不限**；未知字段会 warn（防拼错=不限的静默坑）。
- **计量**：内存滑动窗口，`record` 在每次调用完成时记（token=totalTokens；usage 缺失按 0 token 记但次数/耗时照记）；重启清零，跨重启对账走 monitor 的 `llm_usage`。
- **建议限频**：同一角色 `adviceCooldownMinutes` 内最多一条 `budget_advice`（平稳心跳限频，里程碑异常不受影响）。
- **观测层永不影响请求**：advice/record/install 全部包 try/catch，异常只 warn。
