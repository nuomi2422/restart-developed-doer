## 一、★ 端点 400 根因（本轮最重要的一条，实机抓现行）

> 背景：用户看到「游戏内的 AI 一直说连不上」。**不是模型问题（deepseek-v4.1-flash 正常），
> 也不是网络问题 —— 是我们发出去的一部分请求本身格式非法，被端点确定性拒收（HTTP 400）。**
> 上一轮（第二批收口 §11）只做了「连续拒收→熔断」的止损，根因留给下一轮；本轮抓到了。

### 1.1 现场证据（live `monitor/context.jsonl`，逐条可核）

失败请求的消息数组是 **`[system, Tool, user]`**（roles=`stu`）：

- 那条 `Tool` 的 assistant 调用（tool_calls）**在整份日志里从未出现**（`assistantIdx=-1`）；
- HTTP 400，**同 payload 重试同样 400**（确定性）；
- **循环复现**：15:39 / 18:51 / 19:00 / 19:03 / 19:08（昨）与 03:11 / 03:12 / 03:15、11:25（今）——
  每次模型调 `find_tools` 后必现一轮（展开块 `<functions expanded=…>` 可以单条超预算）。
- ⇒ 这正是「合成木镐卡 16 分钟」背后真正的 400 源头：执行回合每三轮就烧掉一轮。

### 1.2 根因链（三行可核）

1. `CompactSplit.byRecentBudget`：单条消息超预算 → 预算内找不到合法切点 → **`kept=[]`**；
2. `EntityAgentLoop.replayWindow` 的老兜底「至少保最后一条」→ 保的正是那条**大 Tool**；
3. `AgentRequestContext.attach` 附上 system + user → **`[system, Tool, user]`** → 400。

### 1.3 修法（`dfb90399`）

- 新增纯函数 `CompactSplit.validTail(all)`：兜底取「最近一条 + 若为 Tool 则带上其调用方 Assistant」；
  整段历史都是 Tool（坏数据）时返回空 —— **宁缺勿发必然 400 的请求**；
- `replayWindow` 兜底改用它；`byRecentBudget` 正常契约不动
  （`CompactSplitTest.nothingFitsMeansSummarizeEverything` 钉住的「装不下→空段」设计保留）。

### 1.4 实机验证（11:29 重启后）

## 三·五、自编译模块 5 红：javac 诊断解码口径修正（`585c141b`，探针实测）

全仓强制重跑时 `plugins:selfcompile` 出现 5 红（`MutationCompilerCharsetTest`×3、
`MutationCompileErrorVisibilityTest`×1、`MutationPipelineTest`×1），全部指向
**errors.json 空 / 解析不出错误** —— 自编译失败侧整个失效。

**探针实测（同一段 Broken 源、三种 JVM 参数，JDK 21.0.11）**：

```text
file.encoding=UTF-8  native.encoding=GBK  defaultCharset=UTF-8 → javac 字节按 UTF-8 可读
file.encoding=UTF-8  + -Dstderr.encoding=UTF-8                 → javac 字节按 UTF-8 可读
file.encoding=COMPAT native.encoding=GBK  defaultCharset=GBK  → javac 字节按 GBK  可读
```

⇒ **javac 对「我们给的流」用的编码 = `Charset.defaultCharset()`，不是 `native.encoding`。**
2026-09-30 修「errors.json 空」时按 `native.encoding` 解码能过，是因为当时环境
（游戏 JVM `-Dfile.encoding=COMPAT`）里两者**恰好都是 GBK** —— 口径重合，功劳记错了属性。
本轮 JDK21 默认（UTF-8）的测试 JVM 让两者分道，缺陷复现。

**修法**：`MutationCompiler.diagnosticCharset()` 与测试都改跟 `Charset.defaultCharset()`
（游戏 COMPAT 环境行为不变：仍是 GBK 解码）。**测试：54/0（修复前 5 红）。**

> 这条与本轮的 400 根因同属一个家族：**「看起来对」的代理属性在环境变化时分道**。
> 两处都是探针（而非推断）定案。
