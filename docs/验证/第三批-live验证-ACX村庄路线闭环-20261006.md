## 五、本轮记录的盲点 / 待办（用户点名：记录，先不改码）

1. **放置盲区（模型侧）**：ACX 在"自己站的那一格"反复右键放置（工作台），
   报 `right-clicked… nothing visibly changed`，连续重试不换方法；
   工具与物品都正常（主手拿着 crafting_table），**是选位+重试策略的盲区**，
   经主人提示"站开一格再放"后一次成功。床/箱子同理（站旁边放成功）。
2. **基地放置不看通道**：用户观察到"把自己出去的路/门挡住了"——放置无通行性检查，
   且 3 次死亡发生在基地内（逃跑路线被堵是风险因素）。
3. **计划条件看不见容器/熔炉里的物品**：41 原铁在熔炉里烧着，计划（raw_iron≥41）
   读到背包 0 → 重规划让 AI 再采 41 个（重复劳动）。同类：铁锭在炉里时
   `iron_ingot` 条件也不达标。
4. **死亡台账只跟踪 2 种物品**（trackedItemKinds=2，34 件掉落里），
   修复支线以"2 种找回"判定成功关闭——其余 32 种（含铁/工具）无人再催捡。
5. **猎羊任务的世界事实盲区**：村庄附近没有羊（扫到的只有猪/鸡/村民/鱿鱼），
   规划器仍排"杀 3 只羊"（要 20 分钟+多次失败才被改单）。
6. **苦力怕不躲 + 爆炸掉落不捡（用户实况观察）**：遇到苦力怕不主动躲避/撤离，
   被它把基地（家）炸了；爆炸后掉落的物品也不主动捡，等主人提醒才 `collect_items`
   （掉落限时刷新，风险窗口）。基地设施（工作台/箱子/熔炉）事后确认尚在。
7. **"最近容器"解析错误**：`goto block=chest` 曾解析到地下的箱子（726,-36,1111，
   107 格远）而不是身旁 3 格的自家箱子——寻路 NO_PATH 失败。
8. **死亡恢复的正面证据（对照）**：15:35 僵尸杀它掉 104 原铁 → 修复支线派发 →
   它跑到死亡点 `collect_items` **把 104 原铁全捡回**（限时窗口内），随后完成
   两套铁甲 + 两套铁工具。**死亡支线+捡包链路在真机成立。**
