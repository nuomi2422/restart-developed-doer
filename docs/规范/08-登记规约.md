# 08 · 登记规约（以后工具统一放这里）

## 一、铁律
**以后所有新写的工具 / 脚本 / 规范 / Skill / MCP 配置，一律登记到本统一版**，并在 `09-更新日志.md` 追加一条。
不允许再出现「散落三摊、索引断裂」。

## 二、放置规则

| 类型 | 放哪 | 同时登记 |
|---|---|---|
| 运行时脚本（.ps1/.js/.mjs） | `rdd-selfcompile\scripts\` | 本版 `02-工具资产清单.md` + `09-更新日志.md` |
| Skill | `~\.config\opencode\skills\<name>\SKILL.md` | 本版 `02` + 全局 `AGENTS.md` 暗号索引 |
| MCP 服务/配置 | `opencode.json` 的 `mcp` | 本版 `02` + `03` |
| 规范/流程文档 | **本目录** | 本版 `README` 目录 + `09` |
| 设计蓝图/数据流/红线 | `rdd架构\` 根（本版 `00` 指向） | `00-总索引.md` |
| 经验/记忆 | 记忆库（`05`） | `05` + `09` |

## 三、命名规范
- 脚本前缀表用途：`w-`（W 层）`codex-`（C 层）`special-mode-`（编排）`redline-`（红线/巡检）。
- 文档：`NN-中文名.md`，编号连续。
- 版本：破坏性改动才升 v；日常改走 `09-更新日志.md`。

## 四、新增流程
1. 分类（工具/模块/架构级）。
2. 按对应门禁实现（见 `01`）。
3. 登记：本版 `02`/`README` 目录/`09`；Skill 另登记 AGENTS 暗号。
4. 三类回归 + 写测试日志。
5. commit（`[模块名]` 前缀）+ 回滚点。

## 五、维护
- 每次新增/移动/改名，**同步更新 `00-总索引.md` 与 `09-更新日志.md`**。
- 发现新「断链」→ 记入 `00-总索引.md` §C 断链清单，按档位补。
