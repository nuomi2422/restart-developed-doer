## 第一条线：游戏里发生的事 → 变成一条经验

```
① 游戏里出事
   同伴摔死 / 原地打转 / 重复采同一批石头 / 背包和声明的不符 / 修不好
        ↓
② 程序按七条标准筛一遍（值不值得记）
   摔死、打转、重复采集、资产不符、修不好 → 直接记
   浪费、超过预算的采集 → 只有真的浪费了才记
   「我改了检测规则」这种 → 不记（那是改检测器，不是同伴的教训）
   其余六条（做得快、想通了、你自己标了、经验冲突、你说重要）→ 程序判不了，留给 AI
        ↓
③ 排队（写一条待办）
   ★ 实测：真排进去 2 条（都是「摔死」，其中一条是「同一种死法第二次出现」）
        ↓
④ 学习者复盘这条待办 → 写出一份「七项都填齐」的草稿
   七项 = 背后规律 / 什么条件下能用 / 什么情况下会害你 / 看得见的判据
        / 从判据到动作的推导 / 比笨办法省多少 / 证据出处
        ↓
⑤ 过质量门（写全了吗？类型对吗？）
        ↓
⑥ 存进经验库，成为一条正式经验
```

**这条线的实测状态**

| 环节 | 状态 |
|---|---|
| ① 事件被记下来 | ✅ 实测（218 条事件） |
| ② 程序筛 | ✅ 实测（同一种死法第二次出现，被正确识别成「这是模式不是意外」） |
| ③ 排队 | ✅ 实测（2 条） |
| ④ 学习者写草稿 | ⚠️ **只测过，没实机**（我调过，不是游戏里的 AI 自己调的） |
| ⑤ 过质量门 | ⚠️ **只测过，没实机** |
| ⑥ 存进经验库 | ⚠️ **只测过，没实机**（游戏自己落过 1 条） |

**这条线现在最要命的一处**：游戏里的 AI **从来没主动往队列里写过东西**。
我实测过 —— 它一天里调了 52 次「翻工具表」，**一次都没去取「写待办」那个工具**。
所以整条线现在是「入口通、但没人走」。

## 第二条线：经验被用起来 → 结果回流 → 升级或撤回

```
① 干活或规划的时候，程序从经验库里挑几条相关的，摆在 AI 眼前
   （两种方式：一种是每轮自动摆一份「目录」，一种是 AI 主动去翻）
        ↓
② AI 用了其中一条 → 程序记下「这条被用过，什么时候用的」
        ↓
③ 任务做完 → 程序读出这次是成还是败
   ★ 这一格原先是全空的：几千条任务收尾记录里，没一条写着「成」还是「败」
     （原先只记了「急不急」，而「急」不等于「败」—— 实测里「急」里面
       混着真的失败和真的成功）
        ↓
④ 配对：把「那次用经验」和「那个任务的结局」对上
   规则 = 那次用经验之后第一个收尾的任务；超过半小时就当没有
   四种结果：知道成不成 / 还没结束 / 是主人叫停的（不算证据）/ 状态不认识
        ↓
⑤ AI 回报：这经验到底管不管用
        ↓
⑥ 累计够多次成功 → 升级；连着 3 次不管用 → 降级；主人说不可信 → 撤回
```

**这条线的实测状态**

| 环节 | 状态 |
|---|---|
| ① 呈现 + 记下「被用过」 | ✅ 实测 |
| ③ 读出成/败 | ✅ 实测（现在 64 条任务收尾都带真实的「成/败」） |
| ④ 配对 | ✅ **实机点亮过**：一次经验被用 → 任务成功 → 配成「成」→ 判定为有效证据 |
| ⑤ AI 回报 | ❌ **没走通**（游戏里的 AI 一次都没主动回报过） |
| ⑥ 升级/撤回 | ⚠️ 逻辑测过，实机只有人工自测的 1 条 |

**这条线现在最要命的一处**：卡在第 ⑤ 步。
而卡住的原因很具体 —— **每轮自动摆在 AI 眼前的那份「目录」里，只教它「可以去翻经验」，一个字都没教「用完了要回来回报」**。

## 两条线的连接点在哪

```
第一条线产出「经验」  ──────►  第二条线从「经验库」取用
                                        ↓
                            用得好不好 ──► 回流 ──► 升级/降级/撤回
                                        ↓
                              （升级后的经验回到第一条线的⑥，
                                下次被挑中的概率更高）
```

★ **现在这个连接点是通的**（经验库两边都能读写），但**回流那段有一处观测不到**：
「AI 到底翻了哪些工具」这件事，监测台看不见 —— 我上面那些判断只能靠翻 AI 自己的对话记录才知道。

现在经验库是**一堆散在配置根目录的文件**，而且**两种格式混着**：
