
## 二、主构携带器（核心概念）

**一句话**：它是**「分级代替」**——分级判定 + 携带提示，**自己不存任何东西**。

| 属性 | 用户原话/要点 |
|---|---|
| 定位 | **"只是一个携带的东西，它并不储存任何东西，它只负责检测携带任何的东西"** |
| ★ **它携带什么（2026-09-29 更正）** | **不是「4 个工具」**（那是我记错，用户已否）。它携带的是：<br>① **记忆** ② **某些工具（直接执行）** ③ **备忘录** ④ **各种各样的「浮现」** |
| 结构 | **一个接口，让 AI 可以任意写**；它本身也是**一个索引文件** |
| 能力来源 | **"可以调用我们目前的很多的东西"** |
| ⚠️ 风险 | **"肯定要注意那个锁，不然的话左右脑互搏"** ← 与第一批刚关掉的**双驾驶**是同一类问题 |

### ★ 分级检测（用户给的实例，最清楚的一段）
以"**攻击一个很强、之前不知道就死了的怪物**"为例：

| 级 | 检测什么 |
|---|---|
| 第 1 级 | **先判 AI 的攻击命令指向的是谁**（指向了哪个怪物）|
| 第 2 级 | **装备够不够** |
| 第 3 级 | **血量够不够** |
| 结果 | **出提示**（"应该是提示一下而不是阻止"）——**倾向提示，不倾向阻止** |

同类例子（用户举的）：
- **饿死/低血量死** → 加"自身体检"：**血量不满 → 提醒吃东西；饱食度不满 → 提醒吃东西**
- **某次死了** → 在记忆库写下「**地狱很危险**，AI 是怎么死的」→ 之后**规划时规划 AI 会看到**「哇这东西这么难」
  → 也就是：**记忆会抽象**

## 三、学习者（Learner）

- **由学习者自己来写**（即携带器/这些模块的作者）
- **每个小模块在被写时，都带一个"独立管理的经验上下文"**
  - 例：*"我写 AC 怎么失败的、怎么成功的，我（对外）有一个抽象出来的总体经验"*
- ★ **学习者选每个工具去学习时，它自己都能看到"自己以前是怎么写的、写成什么样"**
  ——**这是一个独立管理的东西，作用是「帮助它把资料写好」**（自省/自我历史）。
- **"不是任何的记忆库，就是单纯的独立管理，然后可以自己修"**
- **FC / 携带器 也有与 AC「同款」的版本**（同样的管理方式 + 各种安全措施）
- **不是可以乱改**：**"已经有预算、估计啊、各种各样的"** ← 即带预算/评估等约束
