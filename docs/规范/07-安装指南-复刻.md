# 07 · 安装指南（复刻：把本文档甩给 AI 即可）

> 目标：一台新机器，把本目录 + 本文档交给一个 AI，**照此复刻一套一模一样的**。

## 0. 前置软件
- Node.js ≥18（本机 `D:\rdd\tools\node`，`node.exe`）
- JDK 21（`D:\rdd\tools\jdk21\jdk-21.0.11+10`）、Gradle 9.2（`D:\rdd\workspace\gradle-9.2.0`）
- Edge / Chrome；Minecraft NeoForge 1.21.1 实例 + Numen mod（base + rdd 插件）
- Codex CLI（`gpt-5.6-terra`，中转 API）
- Playwright 浏览器（`ms-playwright`）+ 全局 `@playwright/mcp`

## 1. 目录约定（照搬）
```
D:\rdd\docs\rdd-docs\rdd架构\               # 资料中枢（本目录 + 特殊模式 + 蓝图/数据流/红线 + 测试日志）
D:\rdd\workspace\rdd-selfcompile\   # 运行时脚本真源 + ai-bridge + instances + mutations
D:\rdd\workspace\minecraft-numen\   # Numen 源码
D:\rdd\mc\The Best of Twilight Forest\   # gpt 实例
~\.config\opencode\                 # opencode 配置 + skills
```

## 2. 装 Skills
把 `~\.config\opencode\skills\` 下 `mcp-mc-quest / module-blueprint / gpt-brain / special-mode-loop` 复制过去；
`rdd-selfcompile` 放 `~\.agents\skills\`。`opencode.json` 里配 `skills.paths`。

## 3. 装 MCP
1. **ai-bridge**：复制 `rdd-selfcompile\ai-bridge\`，Chrome 加载 `chrome-extension`，`node mcp-server\index.js install`。
2. **codex**：复制 `scripts\codex-mcp-server.mjs`；`opencode.json` 加 `mcp.codex`（`CODEX_EXE` 指向本机 codex.exe）。
3. **memory**：`npm.cmd i -g @modelcontextprotocol/server-memory`，按 `05` 注册。

## 4. 配 opencode.json（关键块）
```json
{
  "mcp": { "ai-bridge": {...}, "codex": {...}, "memory": {...} },
  "skills": { "paths": ["C:\\Users\\<你>\\.config\\opencode\\skills", "C:\\Users\\<你>\\.agents\\skills"] },
  "provider": { "openrouter": { "options": { "apiKey": "..." } } }
}
```
改完**重启 opencode**。

## 5. 复制运行时脚本
把 `rdd-selfcompile\scripts\*` 全量复制；`config.ps1` 里路径按本机改（SC_ROOT/JAVA_HOME/GRADLE/实例路径）。

## 6. 常驻服务
- **防停 watchdog**：`Start-Process -WindowStyle Hidden powershell -ArgumentList ... every-10min-drive.ps1 -Loop -IntervalSec 600`；复查 `drive-heartbeat.log` 递增。
- **监测台**：`$env:NUMEN_MONITOR_DIR="<实例>\config\numen\monitor"; node rdd-monitor-publish-20260913\monitoring-station\server.mjs` → `http://127.0.0.1:8776/`。

## 7. 进游戏验证
1. `launch-mc.ps1 -Instance gpt -AutoStopMinutes 180`
2. 等世界加载 → `node numen-mcp.js list` → `get_self_status`
3. `/goal` 派目标（`node numen-mcp.js call enqueue @goal.json`，text=`/goal ...`）
4. `node redline-watch.js rdd` 常开巡检；异常写 `04`
5. `rdd_status` 看 `primary_status/subtask_status`；打勾即执行通

## 8. 验收清单（复刻成功的判据）
- [ ] 5 个 skill 可见、暗号（数字1~4）可触发
- [ ] MCP：`ai-bridge check_connection`、`codex_health`、`memory` 工具可见
- [ ] `every-10min-drive` heartbeat 递增；监测台 8776 可开
- [ ] `gradle :rdd-core:test :plugins:rdd:test --rerun-tasks` 全绿（207/0、92/0）
- [ ] 进游戏 `/goal` → 规划出多级 + waitFor；执行打勾（参照红线验证）

## 9. 常见坑
- `.ps1` **必须纯 ASCII 注释**（PS5.1 读 BOM-less UTF-8 中文会吞换行）。
- 浏览器**必须用户亲手启动**（后台进程起的窗口点不动/黑屏）；W 层用 `w-open-browser.bat`。
- 不产出**先排网络/provider**，再判代码。
- W 平台 Qwen 暂不用（验证码）；GLM/Kimi 可用。
- MC 与 gradle 同时跑注意内存（MC 建议 ≤1536m）。
