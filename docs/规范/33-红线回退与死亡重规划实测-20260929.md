## 四、踩坑（本轮新增）

1. `Start-Process powershell -ArgumentList ... '-File', <带空格的路径>` **路径必须自己加引号**，
   否则报「-File??E:\restart... 不是脚本」——`Start-Process` 不会像 `&` 那样自动加。
2. `node xxx.js call tool '{"a":"b"}'` 内联 JSON **在 PS 5.1 下必被拆坏**（本轮第 2 次踩）。
   解法：`mc-call.js` 包装 + 参数走文件。
3. `scan_nearby_entities` 的 `type_filter` 只接受 `hostile|passive|player|all`，**没有 `item`**；
   掉落物要用 `all` 再自己按 `entity.minecraft.item` 过滤。
4. **RDD 任务链跨 MC 重启存活**（`goal-…afd1b2` 重启后仍 ACTIVE）→ 长任务可以分段跑，不必一次开满 60 分钟。
5. `take_items` 生存模式**必然拒绝**（「CREATIVE MODE ONLY」）→ 「给装备」只能靠真实获取，
   别再指望它当测试夹具。
