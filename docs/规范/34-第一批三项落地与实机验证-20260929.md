### ② 卡死检测（LLM 空转）

落点：`RddStallPolicy`（纯函数）+ `RddStallWatcher.track`（一处插入）。**只提前拍醒，不动状态机**。

- `LLM_IDLE_NUDGE_AFTER_CHECKS = 5`（1 次/秒 → 5 秒）
- `llmIdle(source)` 只认 `source=="idle"`；`body_task:*` / `furnace_production` **永不触发**
  （mine/build 多步任务内部会连跑几十秒不发新工具调用，拿 5 秒拍它等于打断正常干活）
- `shouldNudgeLlmIdle` 一次性触发（`==` 而非 `>=`），避免刷屏
  （依据记忆 `bug/parked-silent-flood-per-tick`：曾有一次卡死刷 90+ 条）
- nudge 文案必须**逼它动手 + 自带当前任务**，否则会被当成闲聊
  （依据 batch1 bug#10「nudge 是吹风，AI 回一句话就停」的教训）
- 同步发 `llm_idle_stall` 事件，`action: "nudge-only; state machine untouched"`

**实机证据**（`rdd.jsonl`，全天触发 12 次）：

**判据真的改变了行为路径**（不是只多打一条日志）：failed→retry→再拍→resumed→completed。

### ③ 暂停（PAUSED）—— 状态机就绪，**对外触发面未接线**

- `SubtaskStatus.PAUSED`（新枚举值）
- `TaskChain.pauseSubtask` / `resumeFromPaused` / `isPaused` / `pauseReasonsView`
- 语义边界（写进 javadoc + 单测）：
  - `SKIPPED` = **放弃**（立刻 `advanceOrAwait` 推进，永不回来）
  - `FAILED` = **做不到**（进重试/能力缺口/失败升级循环）
  - `PAUSED` = **先放着**（不推进、不失败、不消耗重试预算，可原地开回来）
- 监督天然不碰它：`RddDetector` 推进路径以 `currentSubtaskStatus() != RUNNING` 为准 → PAUSED 下不派工/不拍醒/不判卡死
- 持久化对称补齐：序列化 / 恢复（旧存档缺 `pauseReasons` 键 = 空，不算损坏）/ `validateRestoredState` 大声拒绝脏数据 /
  `resumeFromReplanning` 与 `replaceCurrentSubtasks` 重置时清 `pauseReasons`（不清会触发
  "restored pauseReason on non-paused subtask"）
- 字节码实证：`javap` 命中 `pauseSubtask` / `resumeFromPaused` / `isPaused` / `pauseReasonsView` / `SubtaskStatus.PAUSED`

## 五、坑清单（本轮新增，可复用）

1. **`Start-Process -ArgumentList` 不自动给带空格的参数加引号** — `w-open-browser`/`w-brain-drive` 这类
   长参数必须自己写 `'"E:\path with space\x.ps1"'`，否则报「-File??E:\restart... 不是脚本」。
2. **闭环节奏 vs Bash 工具 120s/900s 超时** — `run-mutation.ps1` 跑到第 5 段被 kill，
   但 **build/deploy/launch/mcp 四段产物都已落盘**（`phase-*.json` 在）；正确做法是查产物而不是重发。
3. **`mcp-drive.ps1` 只等 TCP 端口，不等世界加载完** — 端口开了但 `list_companions` 仍
   `timed out waiting for the action to finish` → `MCP_FAILED`。
   记忆 `mcp-drive-needed-port-readiness-wait` 只解决了「端口」这一层，**还差「世界就绪」一层**。
4. **W 层"三家都回几十字"先查问题是否被拆词**，别急着判外脑不可用。
5. **写状态机单测前先读真实 API** —— 我连错 3 次（`markCompleted` 不存在、`requireCurrent` 抛
   `IllegalArgumentException` 不是 `IllegalStateException`、多打一个括号）。测试假设错 ≠ 实现错，
   读 xml 报告分清是哪一侧。
6. **`javap` 查方法名，别用 zip 条目名** —— class 文件名是类名，方法在字节码里。
