# 11 · 模块化回滚（已实装）

> 按 `自编译系统\self-compile-rollback.md` 契约**实装**（不再只靠 git）。
## 一、存储（store）

```
D:\rdd\workspace\rdd-selfcompile\selfcompile\
  ├── mutations\                 # 单次编译工作区
  ├── candidates\<module>\<ver>\ # 候选（未验证）
  ├── stable\<module>\<ver>\     # 已验证版本（manifest.json 标 state）
  ├── archive\<mutation-id>\     # 失败/停止归档
  └── active.json                # 当前各模块活动版本指针
```

- 状态机：`REQUESTED → WORKSPACE_CREATED → GENERATED → STATICALLY_CHECKED → COMPILED → CANDIDATE → VERIFIED → DELIVERED`
- **只有 `VERIFIED` 能进 `active`**；`FAILED/ARCHIVED/STOP_LOSS` 不晋级。

## 二、脚本

`D:\rdd\workspace\rdd-selfcompile\scripts\selfcompile-store.js`

```powershell
node selfcompile-store.js status                          # 看 active + 各模块 stable 版本
node selfcompile-store.js promote -m rdd -v <ver> -jar <path> [--state VERIFIED|CANDIDATE] [--parent <commit>] [--note "..."]
node selfcompile-store.js rollback -m rdd [-v <ver>] [--deploy gpt]   # 切 active 指针；--deploy 才复制 jar 到 mods
```

## 三、规则

- **回滚 = 切 `active.json` 指针**到某 `VERIFIED` 版本；默认回滚到「最近一个非当前 VERIFIED」。
- 回滚脚本**不自动把候选 jar 复制到 mods**；`--deploy` 显式才复制 stable jar。
- 每模块回归：`gradle :rdd-core:test :plugins:rdd:test --rerun-tasks`（见 `01` §三）。
- **与 git 的关系**：git 的 tag/branch（模块级回滚点）仍保留；本 store 是「**运行版本指针**」，二者互补。

## 四·补 · 真实缺口（用户 2026-09-27：「应该实装，而不是现在的这个」）

**机制已实装，但库是空的** —— 两者必须分开说清：

| 项 | 状态 |
|---|---|
| 脚本 `selfcompile-store.js`（promote/rollback/status） | ✅ 实装、实测通过 |
| 状态机定义、active 指针机制 | ✅ 实装 |
| `stable\rdd\redline-1-verified\` | ✅ 有 1 个 VERIFIED 版本 |
| `candidates\` | ❌ **空** |
| `archive\` | ❌ **空** |
| `mutations\`（store 内工作区） | ❌ **空** |

**后果**：`rollback` 默认回滚到「最近一个非当前 VERIFIED」——**现在一个都没有**，
所以一旦当前版本坏掉，**回滚只能回到"当前自己"= 等于没得回滚**。
"模块化回滚"目前是**有机制、无库存**。
