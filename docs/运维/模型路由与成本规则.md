# 模型路由与成本规则

RDD 采用 Codex 主指挥官 + 廉价下位 Harness 的级联方式。模型能力和额度会变化，因此每批任务必须以实际证据决定是否升级模型。

## 路由

| 任务 | 首选 | 升级条件 |
|---|---|---|
| 工具级脚本、纯函数、格式转换、只读探针 | OpenCode 免费模型 | 输出不完整、反复询问、测试失败或边界不清时转 Claude CLI |
| 模块级改动、心跳/Monitor/Harness、自编译子模块 | OpenCode 先做局部执行或分析，Codex 规划与验收 | 任一契约、并发、回滚或上下文问题无法局部证明时转 Claude CLI；Codex 最终审查 |
| RDD 核心状态机、跨模块契约、生产或自变异控制面 | Codex 直接规划和审查 | 需要第二意见时调用 Claude/网页模型；不得由免费模型直接决定 |

## 免费模型护栏

- OpenCode 默认 `readonly`；`implement` 必须由 Codex 指定仓库、文件、批次和验证命令。
- 每次调用都保存 JSON 证据；必须包含任务、模型、退出码、命令、改动文件和剩余风险。
- 下位模型连续两次无法完成同一个 `candidate_id`，立即停止该候选并升级 Claude CLI 或由 Codex 重写；不让 Codex 无限修补失控代码。
- 编译通过、MCP 返回 OK 或模型自称完成，都不能替代契约测试、Monitor 证据和真实 MC 世界事实。
- 一次性大范围实装禁止直接落在生产工作树；先用临时 worktree 或 `test` 实例，再按 Promotion Gate 进入 `gpt`。

## Claude CLI 兜底

Claude CLI 用于 OpenCode 输出不稳定、上下文过长、连续失败、需要跨文件调试或需要更强工具调用的批次。Claude 仍受 Codex 批次边界约束，不拥有生产批准权。

## OpenCode 调用

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File `
  "E:\TouhouLittleMaid-HeartPact\scripts\opencode-harness.ps1" `
  -Mode readonly `
  -Task "检查指定工具并报告证据"
```

模型不可用或免费额度耗尽时，记录 `TOOL`/`UNKNOWN` 失败并切换 Claude CLI；不得绕过证据链直接晋级。
