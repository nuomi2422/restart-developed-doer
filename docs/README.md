# docs —— 架构 / 规范 / 验证 / 运维

本目录是项目的文档入口，按四类组织。**规则与流程的唯一真源**在 `规范/`。

| 目录 | 内容 |
|---|---|
| [`规范/`](规范/) | 自编译统一版编号文档（00~67）：工程规范、协议、进游戏巡检、登记约定、阶段规范、回滚规范等 |
| [`架构/`](架构/) | 模块架构与数据流：任务链、经验记忆、世界观测、基地设施、支线决策、懒规划、特殊模式 |
| [`验证/`](验证/) | **实机验证记录**（带原始回执/证据）：世界观测 V1、E0/E1/E2、第二/三批验收、支线决策 |
| [`运维/`](运维/) | 维护者手册、开发者手册、按主题导航、研发叙事时间线、模型路由与成本规则 |

## 从哪份看起

- 想知道**怎么干活/怎么验证** → `规范/00-总纲.md` 起，再按 `运维/50-按主题导航.md`。
- 想知道**某模块怎么设计** → `架构/`。
- 想知道**某功能真的验过没有** → `验证/`（**只列有实机证据的**；未验证的照实标注）。
- 想知道**那天做了什么** → `运维/51-研发叙事时间线.md`。

> 更完整的知识库（含历史/废弃文档）在外部的 RDD 知识库仓库；本仓只收**当前项目相关**的一份。
