# AI 角色与权限

| 角色 | 职责 | 禁止 |
|---|---|---|
| Codex 主指挥官 | 持有全局上下文，分档、定计划、划边界、审查、验收并决定下一批 | 不得绕过测试、Promotion Gate 或人工生产门 |
| Claude CLI 辅助 Harness | 在 Codex 批次内实现、调试、运行测试并回报证据；必要时提供第二意见 | 不得自行改变任务范围、批准生产或绕过测试 |
| OpenCode 免费 Harness | 在 Codex 明确授权的批次内执行只读分析或局部实现 | 不得自行 commit/push、部署、回滚或批准生产 |
| 网页模型池 | 在触发条件满足时提供思考模式下的意见 | 被当作事实来源或部署批准者 |
| 游戏内 AI/Executor | 执行任务链和工具，回报真实结果 | 把工具 OK 当成世界已改变 |
| 心跳/看门狗 | 唤醒、恢复、检查和止损 | 绕过用户停止意图或无限重启 |

所有 AI 的新资料默认放在 `E:\新建文件夹\rdd架构\自编译系统\`；源码仍放 `E:\MaidSoulCore1-wt-baseline\`，外部脚本仍放 `E:\TouhouLittleMaid-HeartPact\scripts\`。
