# 术语表

| 术语 | 含义 |
|---|---|
| **自编译 / 自变异 / selfcompile** | 同一概念：AI 生成/修改 NumenTool 源码，编译打包 jar，游戏内验证 |
| **mutation** | 一次候选变更的完整工作区与生命周期（`mutations/<mutation-id>/`） |
| **NumenTool** | Numen 可注册的游戏内工具（工具 id 用下划线，如 `rdd_whereami`） |
| **candidate / 候选** | 已 `COMPILED` 并经 `MutationArtifactStore` 提升为 `CANDIDATE` 的工件 |
| **gate / 门禁** | 机器可判定的晋级关卡（见 `02-规范/晋级门与状态机.md`） |
| **promotable** | 门禁全过（`promotable=true`）才允许进 `gpt` 基线 |
| **test 实例** | 候选实验用 MC 实例，允许失败/回滚 |
| **gpt 实例** | 通关与生产基准实例，只收通过验证的版本 |
| **DELIVERED** | mutation 终态：jar 已部署到实例 mods |
| **STOP_LOSS** | mutation 终态：止损，不再硬磕 |
| **VERIFIED / 验证** | 用监测台快照/日志/事件/source/classes/jar 哈希校验，证据齐才算 |
| **监测台 Monitor** | 只读观测台（默认 `http://127.0.0.1:8776/`），读 `config/numen/monitor/*.jsonl` |
| **MCP** | 桥接/游戏测试通道（Numen MCP 8765；opencode ai-bridge） |
| **watchdog / 看门狗** | `every-10min-drive.ps1` 每 600s 注入「继续」，防长任务静默停摆 |
| **Harness** | 执行壳：Codex 主指挥官 / Claude / OpenCode 下位 |
| **外脑** | 网页模型（DeepSeek/GPT/ChatGPT），只出意见不当真理 |
| **Promotion Gate** | 候选晋级流水线，见规范 |
| **Kill Switch** | 检测到异常立即 `HALTED`，保留现场通知人工 |
