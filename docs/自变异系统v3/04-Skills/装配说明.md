## 装配/更新约定

- 新增或修改 skill：改**运行时真源**，然后同步一份快照到本目录。
- skill 是「skills 级能力」：暗号索引在 `C:\Users\lenovo\.config\opencode\AGENTS.md` 顶部，
  内容放规定位置，不内联。
- skill 修改后 opencode 需**重启**才重新加载。

## 各 skill 在自变异系统中的角色

- `rdd-selfcompile`：自变异主能力（生成工具→安全编译→打包→部署→MCP 验证→止损）。
- `mcp-mc-quest`（数字1）：长任务轮询通关 MC，为自变异提供一手失败/死亡经验资料。
- `module-blueprint`（数字2）：目标边界补齐单模块，用于扩展自变异子模块设计。
- `gpt-brain`（数字3）：GPT 外脑快速对话，用于方案/计划评审（当参考不当真理）。
