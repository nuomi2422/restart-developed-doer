# MC 通关指南（RDD 规划知识）

这是给 RDD Stage-A/Stage-B 规划器和外部 Harness 的事实参考。它是可更新的知识文档，不是硬编码任务链。

> **定位**：本文件是“可移植的 MC 基础攻略”，与某只同伴自己积累的经验库（`config/numen/experience-<uuid>.jsonl`）是两类知识，不要混为一谈。规划器只把它当参考资料，它不获得修改任务或执行工具的权限。

## 开局路线

石镐、石斧和食物优先；尽快寻找村庄，获取床、干草、小麦、箱子物资和铁傀儡资源。获得水桶后再深度下矿。早期优先补齐两把铁镐、水桶、盾牌、铁斧、床和船；水桶用于防摔、防火、处理岩浆和采集黑曜石。

## 阶段门禁

1. 村庄与食物：床、面包和基础种子。
2. 铁器：至少两把铁镐、盾牌、水桶、铁斧。
3. 钻石与附魔：水桶辅助下矿，制作钻石镐，采集黑曜石，建立附魔台。
4. 下界准备：备用装备、打火石、方块、远程武器和抗火药水；堡垒探索采用封墙、搭高和逐段推进。
5. 末地准备：烈焰棒、末影珍珠、末影之眼、弓箭、药水、食物和水桶；进入末地前确认装备与回退物资。

## 稳态通关基线（普通/困难生存）

这条路线的目标不是最快到末地，而是让同伴在遇到一次死亡、迷路或资源不足后仍能回到可继续推进的状态。规划器应按以下依赖顺序推进，并把每一段绑定到背包或世界事实，不能只写成口号。

1. **基地与复活锚点**：在主世界建一个小型基地，至少有床、箱子、熔炉、工作台和地狱门预留位。重生点应是同伴自己的床旁基地；死亡后优先补给、穿上备用装备，再回收掉落物，不依赖主人所在位置。
2. **食物与基础装备**：优先找村庄，取床、箱子物资、干草块/小麦和种子；把干草块加工成面包，建立可持续食物。铁器阶段备水桶、盾牌、铁镐、火把和方块。
3. **钻石装备与最低附魔**：下矿获得足够钻石，制作并穿戴整套钻石甲、钻石镐和钻石斧；先做一张普通附魔台，获得第一层保护/锋利等基础附魔。不要在资源不足时直接把“满级附魔台”塞进前期任务。
4. **经验设施与备用库存**：若发现主世界刷怪笼，可把它改造成简易经验点：水流集中怪物、在安全格手动击杀、旁边建立补给点。刷怪笼本身是设施，**不能作为 `goto` 的重合终点，更不能被挖掉**；导航必须停在相邻可站立的安全位置。基地至少留一套铁甲、若干铁镐和关键补给；资源富余后再准备第二套钻石甲。
5. **要塞书架与强化**：到达要塞、确认书架资源可用后，才允许将附魔台升级到满级；在经验设施刷经验，为当前战斗套与备用套补保护附魔，并给钻石斧补锋利。此升级有明确资源来源时才是合理分支，不是开局义务。
6. **下界先保命再探索**：先进下界寻找下界疣、烈焰人和烈焰棒，制作酿造台与抗火药水；没有抗火药水前不进行高风险岩浆海/堡垒深入。下界移动必须搭桥、封墙、留退路、逐个引怪，不能直线硬冲。
7. **末地前最后检查**：进末地前在基地保留备用装备和补给；随身带食物、方块、水桶、远程手段、抗火/治疗等药水，并确认末影之眼、要塞传送门与回退库存。末地先处理水晶，再打龙；床只可作为受控爆破工具，绝不当重生点。

## 附魔台的最低有效配置

**早期普通附魔台即可**，不默认追求满级附魔台，也不默认凑 15 个书架。

- 附魔台本身 = 1 本书 + 2 颗钻石 + 4 块黑曜石。这是本阶段真正必须的资产。
- 书架是**可选增益**：没有书架也能附魔，只是等级上限低。只有在当前资产已明显富余、且主人明确要求高级附魔时，才把书架纳入规划。
- 规划材料时按**现有资产 + 最低有效目标**计算，不按“理想满配”计算；已经持有的（钻石镐、黑曜石、书）不重复采集。
- 书 = 3 张纸 + 1 张皮革；纸来自甘蔗。若已持有书或甘蔗，直接复用。

## 下界与末地的特殊规则

**下界不能沿用主世界的水桶灭火方案**：水在下界会瞬间蒸发，无法用来灭火、造黑曜石或当落地缓冲。下界抗火依赖**抗火药水**和装备，不依赖水桶。

**床在下界和末地会爆炸**：床不是可用的重生点，也不能当普通家具放置。它在那两个维度是**爆破工具**（对末影龙、对下界推进有用），不是补给品。真正的重生点仍靠主世界床 + 重生锚（下界用萤石充能）。

因此“下界准备”里不含床和水桶，改为抗火药水、方块、食物与远程武器。

## 生电发展顺序

村庄 → 繁殖机/农场 → 刷铁机 → 交易所 → 钻石装备与药水；刷石机 → 刷怪塔 → 树场、羊毛机和分类存储。高阶自动化（潜影贝、经验农场、全物品）必须建立在稳定的基础资源和安全回滚点上。

> 生电是**可选分支**，不是通关必经路径。当主人的目标是“通关”时，不为生电回路额外扩大任务量。

## 风险清单

苦力怕、铁傀儡误伤、普通怪、掠夺者、监守者、摔落、火焰与岩浆是常见死亡原因。每个阶段的任务必须给出真实物品命名空间和数量，工具成功必须用背包/世界事实复核。

## 失败分诊（取代旧版“失败即能力缺口”的因果）

工具（如 AutoMine）失败时，**先分诊原因，不要直接推断“能力缺口”**。按以下顺序区分：

1. **资源耗尽 / 目标不存在**：例如附近确实没有该矿石，或目标物品不足。处理方式：扩大搜索范围、换目标区域，或先补资源。
2. **路径不可达**：例如深埋矿、被流体或基岩阻挡。处理方式：改路线、分层下探，或换用其他手段。
3. **工具执行失败**：工具自身报错、参数形状不对（如把物品 ID 当方块 ID 传入）。处理方式：修正调用参数后重试。
4. **程序缺陷**：以上都排除后仍稳定复现的失败。此时才记录缺陷并上报。

**未知原因就保持未知**：不许在没有证据的情况下把失败归因成“缺软件工具”或“等待自编译”。反复失败不等于没有对应工具。

## 给规划器的约束

- 已持有的装备和设施不重复规划，消耗品才按需补量。
- 目标拆成可检测资产，不把“找到村庄”直接当成完成，必须绑定村庄相关物资或世界事实。
- 阶段递进按**现有资产 + 最低有效目标**计算，不按理想满配计算（附魔台案例见上）。
- 高风险步骤（深埋矿、下界、末地）必须给出明确的失败分诊与回退动作，而不是笼统地“停车等待”。
