| 项 | 值 |

| 存档 | gpt（生产）/ test（实验） |

Windows 执行策略阻止直接跑 `.ps1` 时，用：
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File <脚本>
```

## 完整单轮（真实闭环，主入口）

```powershell
.\scripts\run-mutation.ps1 -Requirement "你的需求描述"
```

流程：

```text
创建 mutation-id
→ build-jar 编译打包
→ deploy 部署 mods
→ launch-mc 启动 gpt 存档
→ mcp-drive MCP 调用工具
→ verify 读监测台判定
→ 产出 verdict.json
```

## 不打游戏（编译 + 部署 + 验证）

```powershell
.\scripts\run-mutation.ps1 -Requirement "xxx" -SkipLaunch -SkipMcp
```

## 手动等 MCP

游戏启动后等 Numen MCP（8765）就绪（1~3 分钟），单独跑：

```powershell
.\scripts\mcp-drive.ps1 -MutationId <id> -ToolName selfcompile_status
.\scripts\verify.ps1 -MutationId <id>
```

## 止损重试循环
