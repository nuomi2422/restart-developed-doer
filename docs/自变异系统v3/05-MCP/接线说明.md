# MCP 接线说明

自变异系统涉及两套 MCP：

## 1. Numen MCP（游戏内工具通道）

| 项 | 值 |
|---|---|
| 配置 | `E:\.minecraft\versions\The Best of Twilight Forest\config\numen\mcp_server.json` |
| 地址 | `127.0.0.1:8765`（`enabled=true`） |
| token | 配置内 `token`（本目录快照已脱敏） |
| 调用超时 | `call_timeout_seconds: 300` |
| 隐藏工具 | `todowrite`、`load_skill` |
| assist | `true` |

用途：外部脚本 `mcp-drive.ps1` 通过它调用 NumenTool（如 `selfcompile_status`、`rdd_whereami`）并读事件。
快照：`05-MCP/numen/mcp_server.json`、`mcp_clients.json`（均脱敏）。

> 免费 AI 硬约束：不得向 MC/MCP 投递执行指令（enqueue/mine/goto/attack/build 等）；
> 只读查询（get_self_status / scan_nearby_entities / rdd_get_inventory 等）作为观察手段。

## 2. opencode Harness 的 ai-bridge MCP

| 项 | 值 |
|---|---|
| 配置 | `C:\Users\lenovo\.config\opencode\opencode.json` → `mcp.ai-bridge` |
| 类型 | local |
| command | `D:\nodejs\node.exe  E:\restart developing doer\rdd-selfcompile\ai-bridge\mcp-server\index.js` |
| 环境 | `AI_BRIDGE_MCP_TOKEN`（本目录不落，见原位） |
| timeout | `2400000`（40 分钟；长任务用） |
| enabled | true |

片段（脱敏）：

```json
"mcp": {
  "ai-bridge": {
    "type": "local",
    "command": ["D:\\nodejs\\node.exe", "E:\\restart developing doer\\rdd-selfcompile\\ai-bridge\\mcp-server\\index.js"],
    "environment": { "AI_BRIDGE_MCP_TOKEN": "***REDACTED***" },
    "timeout": 2400000,
    "enabled": true
  }
}
```

用途：与浏览器里的外脑（ChatGPT/DeepSeek 页）快速对话，见 skill `gpt-brain`（数字3）。
启动链路脚本：`03-脚本/scripts/start-ai-bridge.ps1`、`open-ai-bridge-chrome.ps1`。
