# 三档任务模型

> 发现隐藏复杂度时只能从一档升二档、从二档升三档，**不能降档**。

## 一档：工具级

范围：单个工具、简单测试工具、局部脚本或文档修正。
审批：AI 可自行完成，Codex review 可选；不因等待其他模型或用户而停工。
门禁：仍需最小测试、日志和结果记录；面向行为验证。

## 二档：模块级（Bounded）

范围：心跳、Monitor 看门狗、双实例脚本、Bridge 接入、Harness 小模块、自编译子模块。
审批：Codex 负责规划、边界和验收，Claude/OpenCode 在批次内执行并回报；
存在真实架构取舍时再调用网页模型。只有跨模块、高危冲突、不可替代信息缺失时才暂停升级。
门禁：工作流文档先行；外脑 + 免费交叉审。

## 三档：架构级（Architectural）

范围：改变 RDD 核心架构、跨模块契约、生产/安全模型或自变异控制边界。
审批：必须走完整九步编程流：分类、探索、逐问澄清、方案、外脑意见、设计、**用户批准**、实现计划、闭合验证。
门禁：完整九步流 + 证据；每 1h 或每 4 轮激活 Codex 审查。

## 最高难 / 高风险

**留人工待批**：先跳过，不越权。Codex / 外脑没接好前，以「留下清晰交接与人工待批标记」收尾，不硬写。

## 多模型评审触发条件

架构/自变异设计、连续两次失败仍找不到根因、生产交付前、用户明确要求。
网页模型必须开启思考/推理模式；记录摘要意见和来源，不记录或索要隐藏思维过程。
最终决策由主协调 AI 基于源码、测试、日志和 MC 世界事实作出。
