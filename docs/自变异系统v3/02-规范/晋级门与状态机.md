# 晋级门（Promotion Gate）与自治状态机

> 来源：`自编译系统/architecture/promotion-gate.md`、`architecture/state-machine.md`。

## Promotion Gate（晋级门）

候选能力必须按顺序通过以下**机器可判定**门禁，缺少任一证据不得进入 `gpt`：

```text
CANDIDATE
  → BUILD_PASS
  → CONTRACT_PASS
  → TEST_RUNTIME_PASS
  → MONITOR_HEALTHY
  → WORLD_FACT_PASS
  → NO_UNRESOLVED_FAULT
  → PROMOTABLE
  → GPT_BASELINE
```

每次晋级记录至少包含：`candidate_id`、`parent_commit`、变更文件/行、测试实例、各 gate 状态、
证据路径、未解决故障列表、`promotable` 布尔值。只有 `promotable=true` 才能进 GPT 基线；
**进入生产仍需人工批准**。

## 自治状态机与权限

```text
INIT → RUNNING → RETRYING → REPLANNING → SELF_COMPILING
                                   ↓             ↓
                               DEGRADED       TESTING
                                                 ↓
                                           PROMOTABLE
                                                 ↓
                                           BASELINE
                                                 ↓
                                           PRODUCTION
                                                 ↓
                                           ROLLBACK
任意状态 → HALTED（Safety Gate / Kill Switch）
```

状态转移权限固定：

| 转移 | 负责者 |
|---|---|
| `RUNNING→RETRYING` | Executor |
| `RETRYING→REPLANNING` | Supervisor |
| 进入 `SELF_COMPILING` | 策略门 |
| `SELF_COMPILING→TESTING` | Self-Compile |
| `TESTING→PROMOTABLE` | Test Gate |
| `PROMOTABLE→BASELINE` | Promotion Gate |
| `BASELINE→PRODUCTION` | **人工批准** |
| `ROLLBACK/HALTED` | Watchdog 只能触发基础设施恢复或此二者，不能重规划 |

## 实例、锁与事件事实层

`test`/`gpt`/未来 benchmark/recovery 实例通过 InstanceRegistry 分配独立
`gameDir/world/logs/monitor/websocket`；启动前持有 `instance.lock` 与 `monitor.lock`，
端口由注册表动态分配（当前默认 test=8765、gpt=8766，可调整）。
结构化 `events/*.jsonl` 是机器控制面，Markdown 是人类/AI 解释层，
二者通过 `candidate_id`/`task_id`/`execution_id` 关联。

## 故障分类与 Kill Switch

故障统一分类为 `BUILD / CONTRACT / TOOL / RUNTIME / TEST / ARCHITECTURE / UNKNOWN`。
编译失败优先本地/Codex 调试；工具失败优先重试或换工具；运行时失败交 Monitor/Supervisor；
架构失败才触发网页外脑评审。

**Kill Switch** 在检测到下列情况立即 `HALTED`（停止自动改码/部署，保留现场并通知人工）：
多实例串台、证据链缺失、Watchdog 连续恢复失败、生产门禁绕过、不可解释状态转移。
